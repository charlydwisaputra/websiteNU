## About Laravel

Laravel is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Laravel takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://laravel.com/docs/routing).
- [Powerful dependency injection container](https://laravel.com/docs/container).
- Multiple back-ends for [session](https://laravel.com/docs/session) and [cache](https://laravel.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://laravel.com/docs/eloquent).
- Database agnostic [schema migrations](https://laravel.com/docs/migrations).
- [Robust background job processing](https://laravel.com/docs/queues).
- [Real-time event broadcasting](https://laravel.com/docs/broadcasting).

Laravel is accessible, powerful, and provides tools required for large, robust applications.

### Pedoman Lambang Resmi NU dan Aset Brand

#### 1. Berkas Brand yang Wajib Ada
Seluruh aset brand permanen milik website disimpan di bawah direktori `public/images/brand/` dan dipanggil menggunakan helper `asset()`:
* `public/images/brand/logo-nu.png`: Lambang resmi Nahdlatul Ulama transparan (resolusi tinggi) untuk navbar, footer, halaman login/guest, sidebar/rail panel admin, serta header kartu tanda anggota (KTA).
* `public/images/brand/logo-nu-sm.png`: Lambang resmi NU berukuran 128px untuk favicon PNG dan apple-touch-icon.
* `public/images/brand/logo-nu.svg`: Berkas master vektor lambang resmi NU tanpa kehilangan detail.
* `public/images/brand/favicon.ico` dan `public/favicon.ico`: Favicon multi-resolusi (16, 32, 48px).
* `public/images/banom/`: Berkas logo bawaan 6 badan otonom (`MuslimatNU.png`, `FATAYAT-NU.png`, `GP-Ansor.png`, `IPNU.png`, `IPPNU.png`, `PMII.png`) yang selalu tersedia di dalam repositori git sebagai fallback otomatis jika berkas di storage belum ada.

#### 2. Konfigurasi Server Baru: `php artisan storage:link`
Berkas logo banom yang diunggah oleh administrator disimpan di disk publik Laravel (`storage/app/public/logo-organisasi`).
Pada saat instalasi baru di server lokal maupun server produksi, jalankan perintah berikut untuk membuat symbolic link dari direktori `storage/app/public` ke `public/storage`:

```bash
php artisan storage:link
```

> **Keamanan & Kestabilan Layout:**
> Sistem telah dilengkapi dengan fallback idempoten (`Banom::resolveLogoUrl()`). Jika symlink storage belum dipasang atau berkas storage belum tersedia di server baru, sistem secara otomatis beralih memanggil logo bawaan di `public/images/banom/` sehingga tidak akan pernah terjadi gambar rusak (broken image) pada Beranda, Ekosistem, Tentang, maupun panel admin.

## Banner Video Beranda (Hero Video)

Banner video Beranda dapat diganti secara dinamis oleh administrator melalui panel admin tanpa perlu mengubah kode sumber.

### Cara Mengganti Video Melalui Admin
1. Masuk ke halaman **Pengaturan Situs** di panel admin: `/admin/pengaturan`.
2. Pada seksi **Banner Video Beranda (Hero Media)**:
   - **Video Banner Desktop**: Unggah video untuk tampilan layar lebar / desktop (format MP4 atau WebM, maksimal 15 MB).
   - **Video Banner Mobile (Opsional)**: Unggah video berorientasi vertikal/potret khusus untuk layar HP (format MP4 atau WebM, maksimal 15 MB). Jika tidak diunggah, versi desktop akan dipakai bersama.
   - **Gambar Poster Hero**: Unggah gambar diam (format WebP atau JPG, maksimal 4 MB) yang akan ditampilkan saat video sedang dimuat atau ketika pengunjung mengaktifkan mode hemat data / pengurangan animasi.
3. Klik tombol **Simpan Pengaturan**. Berkas otomatis tersimpan di `storage/app/public/hero` dan berkas lama akan dibersihkan secara otomatis.
4. Untuk kembali ke video dan foto pemandangan default sistem (`public/videos/village_sample.mp4` dan `public/images/banner-1-*.webp`), centang opsi **Hapus video/poster ini** lalu simpan.

### Spesifikasi Video yang Disarankan
- **Format Kontainer**: MP4 (H.264) dan/atau WebM (VP9).
- **Resolusi Desktop**: 1920x1080 (16:9).
- **Resolusi Mobile**: 1080x1920 (9:16) atau 720x1280.
- **Frame Rate**: 24 – 30 fps (stabil).
- **Durasi Rekomendasi**: 10 – 20 detik dengan transisi looping yang mulus (*seamless loop*).
- **Bitrate Rekomendasi**:
  - Desktop: 1.5 Mbps – 2.5 Mbps (target ukuran < 8 MB).
  - Mobile: 800 kbps – 1.2 Mbps (target ukuran < 4 MB).
- **Audio**: Hapus kanal audio (*mute*) sepenuhnya dari berkas video untuk menghemat ukuran berkas (*bandwidth savings*).

### Contoh Perintah Kompresi dengan FFmpeg

Gunakan perintah `ffmpeg` berikut di terminal untuk menghasilkan video web yang ringan, cepat dimuat, dan kompatibel luas:

1. **Kompresi ke MP4 H.264 Web-Optimized (Hapus Audio & Faststart):**
   ```bash
   ffmpeg -i input_mentah.mp4 -an -vcodec libx264 -crf 26 -preset slow -movflags +faststart -vf "scale=1920:-2" hero_desktop.mp4
   ```

2. **Kompresi ke WebM VP9 (Ukuran Lebih Ringan):**
   ```bash
   ffmpeg -i input_mentah.mp4 -an -c:v libvpx-vp9 -crf 32 -b:v 0 -vf "scale=1920:-2" hero_desktop.webm
   ```

3. **Versi Vertikal untuk Mobile (Potret 9:16 atau Crop Tengah):**
   ```bash
   ffmpeg -i input_mentah_mobile.mp4 -an -vcodec libx264 -crf 27 -preset slow -movflags +faststart -vf "scale=720:1280:force_original_aspect_ratio=increase,crop=720:1280" hero_mobile.mp4
   ```

4. **Ekstrak Poster Gambar Diam (WebP/JPG) dari Detik Pertama:**
   ```bash
   # Format WebP:
   ffmpeg -ss 00:00:01 -i hero_desktop.mp4 -vframes 1 -q:v 80 hero_poster.webp

   # Atau format JPEG:
   ffmpeg -ss 00:00:01 -i hero_desktop.mp4 -vframes 1 -q:v 2 hero_poster.jpg
   ```

## Cara Mengubah Konten Halaman Tentang

Seluruh teks statis pada halaman `/tentang` (deskripsi banner, sejarah, kutipan, visi, misi, kegiatan rutin, koordinat peta) **bersumber dari satu file terpusat**:

```
config/organisasi.php
```

### Langkah-Langkah

1. **Buka** `config/organisasi.php` dengan editor teks.
2. **Cari kunci** yang ingin diubah. Setiap bagian disertai komentar bahasa Indonesia yang menjelaskan fungsinya, misalnya:
   - `tentang_deskripsi` — kalimat pembuka di banner halaman Tentang.
   - `sejarah` — array berisi paragraf-paragraf sejarah (tambah/kurang elemen array sesuka hati).
   - `sejarah_kutipan` — kutipan yang ditampilkan dalam kotak blockquote.
   - `visi` — pernyataan visi organisasi.
   - `misi` — array berisi butir-butir misi (tambah/kurang elemen array sesuka hati).
   - `kegiatan_rutin` — array kartu kegiatan (nama, jadwal, lokasi, peserta, icon).
   - `peta.lat` / `peta.lng` / `peta.zoom` — koordinat dan zoom peta Leaflet di halaman Tentang.
3. **Simpan** perubahan.
4. **Bersihkan cache konfigurasi** agar perubahan langsung berlaku:
   ```bash
   php artisan config:clear
   ```
   > Di production, jalankan juga `php artisan config:cache` setelah `config:clear` agar lebih cepat.

### Catatan Penting

- **Jangan ubah teks langsung di file Blade** (`resources/views/tentang.blade.php`). Blade hanya membaca variabel dari controller — perubahan di Blade tidak akan bertahan dan akan membuat konten tidak sinkron.
- **Pengurus** (Syuriyah & Tanfidziyah) diambil **langsung dari database** tabel `anggota` (`is_pengurus = true`, status Aktif). Untuk mengubah data pengurus, gunakan panel admin → Data Anggota.
- **Koordinat lokasi** juga dapat diatur via environment variable:
  ```env
  ORGANISASI_LAT=-7.4218
  ORGANISASI_LNG=109.1608
  ```
